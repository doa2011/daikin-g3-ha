# G3 接入预检（无型号/固件限制）

配置流程不根据型号、固件版本或协议版本字段拒绝设备。

1. 连接用户输入的地址并执行只读 `/api/v1/info` 请求。
2. 只要求响应可由现有 MessagePack 解码器解析为 map/dict。
3. `model`、`version` 等字段仅作为信息展示，不参与准入判断；字段缺失、未知型号均允许继续。
4. `/api/v1/capabilities` 尽力读取；接口失败、返回空列表或结构不匹配都不阻止创建集成。
5. 不在配置阶段请求 status，也不发送写入命令。

密码可留空；如果用户填写密码，设备自身仍会决定是否接受请求。401/403 会作为设备返回的认证错误显示，不绕过设备认证。

这意味着集成不再限制设备型号、固件版本、TMCP/wire 版本或能力列表。网络不可达、HTTP 请求失败、响应无法解码为 MessagePack map 等实际通信问题仍会报告。
